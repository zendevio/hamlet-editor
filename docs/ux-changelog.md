# UX changelog

User-facing behaviour changes made during the 2026 bug-hunting pass, so each
can be reviewed or reverted on its own. Revert an entry with
`git revert <commit>`.

| Date | Change | Why | Commit |
| --- | --- | --- | --- |
| 2026-10-20 | Hero trinket pickers offer inventory first with counts, explicit catalogue creation second, and Unequip to inventory. Inventory equip consumes one; replacement and unequip return the old item. Loaded class restrictions filter choices. Missing estate blocks transfers, and Discard All restores both files; single-hero Revert directs equipment edits to Discard All. | Prevent silent copying or destruction of trinkets. To revert, undo the lane M picker, trinket helper and store integration together, including the single-hero Revert guard. | Commit pending |
| 2026-10-20 | HP, stress and torchlight resync their thumb after adjusted or ignored commits without losing focus. Fractional HP maxima and saved hints use one decimal, and labels never show an outlying current step above the real max. | Keep displayed bounds and committed steps consistent. To revert, undo the lane M control adapter, shared slider wrapper and HP label changes together. | Commit pending |
| 2026-10-20 | HP, stress and torchlight thumbs use step-aligned ranges and exact track positions; stationary thumb clicks and drags back to the starting value preserve saved fractions. | Match rendered thumb positions to pointer input and prevent accidental HP reductions. Real save bounds still clamp edits. | c2aeb7e |
| 2026-10-20 | HP, stress and torchlight labels show the slider step with the exact saved value when different. Lowering buffed HP keeps the on-disk HP in the slider range until Save. | Explain preserved fractions and allow returning to the previous HP range before saving. | 9602d95 |
| 2026-10-20 | Unchanged HP, stress and torchlight slider clicks and drags back to the starting step preserve saved fractions. Keyboard and pointer changes stay within the real bounds, including fractional HP maxima. | Bits UI commits snapped values even without a changed step and can report a step above a fractional max. | 858ff75 |
| 2026-10-20 | Saving unrelated fields preserves unequal duplicate float values after JavaScript converts whole floats to integers. Returned equipped trinkets contain only estate `id`, `type` and `amount` fields. | Preserve hidden duplicate data and keep hero-only metadata out of estate storage. | 858ff75 |
| 2026-10-20 | An unreadable inactive raid blocks dismissal while the rest of the profile remains editable. Inactive raids, including top-level raid files, are read-only reference data. | Keep unknown hero references safe without preventing unrelated profile edits. | 858ff75 |
| 2026-10-20 | Escape cancels and blurs the estate-name input; a later focus starts editing normally. Stale profiles offer Discard and Cancel when closing. | Avoid dropped name edits after Escape and a Save and Close option that cannot succeed. | 858ff75 |
| 2026-10-20 | Viewing heroes and updating controls after Discard keep the profile clean. HP displays rounded values while retaining saved fractions; the slider includes existing HP above the class base max. Heal to Max and Heal All only raise HP to the base max and keep higher HP. Confirmed Discard and Close completes without reopening the prompt. | Prevent slider normalization and unchanged controls from rewriting saves or trapping the close flow. Class HP excludes buffs, so healing must never lower existing HP. | 1ee3dea |
| 2026-10-20 | Dismissal returns equipped trinkets to estate storage, keeps four last-party slots, compacts purchase keys and blocks the final hero or heroes referenced by an inactive raid. Stale Reload offers Discard and Cancel. Startup window modes are passed to the native builder; macOS maximization still queues after the window is ordered front. | Preserve equipment and game references and avoid an unusable Save choice. Startup flash prevention remains unverified. | 177fb77 |
| 2026-10-20 | Town building headers and treatment rows wrap within their columns; long hero names and classes truncate with full-text tooltips, and Release buttons can wrap. | Keep expanded Sanitarium cards within the grid at 1366x768 while retaining the wide-window layout. | a321845 |
| 2026-10-20 | Wallet currencies, including blueprints, are capped at 999,999,999. Hero and estate names reject a leading ###. Stale profiles require a guarded Reload. Unknown upgrade hashes remain visible and read-only. Dismissal removes per-hero purchases and last-party entries while retaining history. Plot and Courtyard raid abandonment is blocked pending in-game verification. | Leave i32 headroom for game income and protect cross-session and cross-file state. | ad7692c |
| 2026-10-19 | Removed the "Steam Cloud Active" header badge and the path-based cloud callout in the setup wizard. Replaced them with a static note in the wizard's save-folder step and a Steam Cloud section in the README. | Owner request: the detection was a heuristic (any `userdata` path) that was not worth maintaining. | dd578b4 |
| 2026-10-19 | Raid torchlight and hunger use the saved fields; scouting control removed; abandoning returns living party members to town and can be discarded before saving. Districts list existing Crimson Court entries with their saved built state. | Prevent invalid raid fields, stale party status and invented district records. | 7fc077b |
| 2026-10-19 | Wallet, invitations, blood and blueprints accept only whole amounts from 0 to 2147483647 and display inline errors; missing entries are created with verified types. Hero names trim surrounding spaces, use an editor limit of 32 Unicode characters, and reject controls and invisible formatting. Living heroes cannot be edited below 1 HP. | Prevent invalid values and unsafe names from reaching save data. | 7fc077b |
| 2026-10-19 | Dismissal explains and blocks treatment, party, upgrade and other save references. Revival, including batch revival, is unavailable until a complete dead-hero transition is verified. Crimson Curse stages can only replace one existing stage through the curse selector. | Preserve references and prevent partial revival or new curse injection. | 7fc077b |
| 2026-10-19 | Switching profiles or save/game paths with edits asks Save, Discard or Cancel. Save & Close uses normal validation, save blocks and optional auto-backup. A failed auto-backup aborts saving and keeps edits. | Prevent silent edit loss and ensure close/switch flows honor the same save protections. | 7fc077b |
